## 📖 서론  
오늘 발표된 세 편의 논문은 **멀티모달 대형 언어 모델이 도시 수준의 공간 인식을 실시간 행동으로 전환하는 방법**, **추론 시 약점을 보완해 작은 모델의 성능을 끌어올리는 새로운 프레임워크**, 그리고 **에이전트 경험을 영구 지식으로 전환해 기술 진화에 가속을 붙이는 기술**을 제시합니다. 이 모든 발전은 자율 시스템이 환경과 상호작용하고 자기 자신을 개선하는 범위를 크게 확장합니다.

## 📚 본문  

### 1️⃣ UrbanGround: From Local Perception to Spatial Agency in a Real‑Scale City  
- **핵심 혁신**  
  - **멀티모달 LLM(MLLM)**이 거리 풍경을 해석하고, **지리적·시간적 연속성을 유지**하면서 행동 계획을 세울 수 있는 프레임워크 제시.  
  - **“지역 인식이 전역 행동으로 전이되는지”**를 검증하기 위한 대도시 규모 시뮬레이션을 구축.  
- **실무 응용**  
  - **스마트 시티 관리**: 교통 흐름, 재난 대응, 인프라 점검 등에 현장 영상 → 즉각적인 정책/작업 지시 전환.  
  - **자율 로봇/드론**: 거리 수준 perception을 기반으로 한 경로 계획 및 동적 환경 적응이 가능해짐.  

### 2️⃣ CritICL: Inference‑Time Weak‑to‑Strong Generalization from Small Language Model Failure Modes  
- **핵심 혁신**  
  - **추론 시 약점(실패 모드)**을 탐지하고, 이를 **약한 모델의 피드백을 활용해 강력한 모델의 답변을 재구성**하는 “Weak‑to‑Strong” 파이프라인 구축.  
  - 반복 생성·외부 검증 대신 **단일 추론 단계**에서 모델 간 오류 보정 가능.  
- **실무 응용**  
  - **대규모 서비스**: 작은 모델이 빠르게 오류를 포착해 대형 모델의 답변을 즉시 수정 → 고객 지원, 콘텐츠 검증 등 실시간 품질 보증.  
  - **에이전시 내 검증**: 다중 에이전트 협업 시, 작은 모델이 비정상적인 행동(예: 비현실적 계획)을 탐지해 강력한 모델을 제어·수정.  

### 3️⃣ WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution  
- **핵심 혁신**  
  - **에이전트 경험을 구조화된 “스킬”로 압축**하고, 이를 **지속적인 메모리(지식베이스)**에 저장해 재사용 가능하게 함.  
  - 경험 기반 스킬 자동 탐지와 진화 메커니즘을 제공, 에이전트가 **학습·적용·수정**을 순환적으로 수행하도록 지원.  
- **실무 응용**  
  - **자율 작업 흐름**: 특정 업무(예: 일정 관리, 데이터 분석) → 스킬화 후 다른 프로젝트에서도 재활용 가능.  
  - **에이전시 성장**: 신규 프로젝트가 시작될 때 기존 스킬을 기반으로 초기 성능을 크게 향상시켜 학습 비용 절감.
