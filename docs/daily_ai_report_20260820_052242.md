- **핵심 혁신**  
  - **역할‑중심 데이터 설계**: 각 이미지 생성 작업(예: 스타일 전이, 물체 생성)을 “역할” 단위로 나누고, 역할 간 **co‑evolving** 관계를 모델링함.  
  - **동적 재조정 파이프라인**: 데이터 재균형·리캡션을 **실시간**으로 조정해, 드문 스타일이나 소수 클래스도 효율적으로 학습 가능.  
- **실무 응용 방안**  
  - **정원 에이전시**가 제공하는 맞춤형 콘텐츠(예: 식물 질병 진단 시각화, 정원 디자인 시뮬레이션)에서 **다양한 스타일·구성을 자동 생성**할 수 있음.  
  - 데이터 파이프라인에 **역할 메타데이터**를 삽입해, 특정 고객 요구(예: “고대 로마 정원”)에 맞는 이미지를 빠르게 생성하도록 커스터마이징.

  - 정원 에이전시가 수집한 **식물 성장 데이터**를 **자동 보고서**(예: “2026년 8월 토마토 성장 현황”)로 구조화하고, **품질 보증**을 위해 별도 검증 에이전트를 두어 정확도를 보장.
