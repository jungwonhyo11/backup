## 📚 본문  

### 1️⃣ SPADE: Self‑Play in Adaptive Synthetic Executable Environments  
- **핵심 혁신**  
  - **동적 목표 분포**: 학습 에이전트가 스스로 생성·수정하는 목표 집합을 지속적으로 확장함으로써, 기존 고정된 환경池와 달리 “고정 목표” 제약을 제거.  
  - **Self‑Play 기반 환경 생성**: 에이전트가 만든 작업·시나리오를 실시간으로 평가·피드백하여, 다양하고 적응적인 실행 환경을 자동으로 구성.  
  - **Scalable Self‑Improvement**: 목표가 무한히 증가함에 따라 학습 곡선이 가속화되며, 언어 에이전트의 일반화 능력이 크게 향상.  

- **실무 응용 방안**  
  - **자율 콘텐츠 생성**: 우리 정원 에이전시가 자체적으로 새로운 프로젝트·제안서 템플릿을 생성·평가하도록 하여, 고객 맞춤형 콘텐츠 생산 주기를 단축.  
  - **시뮬레이션 기반 전략 시뮬레이션**: 다양한 고객 시나리오를 자동으로 생성·테스트해 최적 전략을 사전에 탐색, 실제 실행 전 위험을 최소화.

### 2️⃣ ADEPT: Accelerating Dexterity via Pre‑Training and Post‑Training using Reinforcement Learning  
- **핵심 혁신**  
  - **대규모 Pre‑Training + Post‑Training 파이프라인**: 고도F(DoF) 로봇이 **시뮬레이션 → 실제**(sim‑to‑real) 전이 학습을 효율적으로 수행하도록 설계.  
  - **Visuo‑Tactile Perception**: 원시 비전·촉각 입력에서 직접 작업 명령을 학습, 긴 목표 시퀀스(长 horizon tasks)에서도 안정적인 실행 가능.  
  - **Dexterity Transferability**: 다양한 로봇 형상과 작업 환경에 적용 가능한 **전달 가능한 Dexterity 모델**을 제공.  

- **실무 응용 방안**  
  - **자율 로봇 어시스턴트**: 정원 관리 로봇이 식물 상태를 감지하고, 정밀한 가지치기·식재 작업을 원시 촉각 피드백으로 수행하도록 제어.  
  - **다중 로봇 협업**: 다양한 로봇 모델을 동일 파이프라인으로 전환해, 현장 작업자와의 협업 시 효율적인 작업 분배 및 실행이 가능.

### 3️⃣ Beyond Teacher Likelihood: Group‑Calibrated On‑Policy Distillation for Long‑Context Reasoning  
- **핵심 혁신**  
  - **그룹‑캘리브레이션**: 여러 약한 학생을 동시에 학습시키면서 **그룹 전체의 성능을 교정**하여, 개별 학생이 놓치는 전역적 정보(전체 입력·전체 목표)를 보완.  
  - **On‑Policy Distillation**: 학생이 자체 생성한 답변을 teacher 피드백 대신 **자체 피드백 루프**로 학습, 장문 컨텍스트에서도 전역적 일관성을 유지.  
  - **긴 입력·전역적 제약**: 토큰‑레벨 피드백이 아닌 전체 입력 구조와 목표 제약을 고려해, **전역적 오류**와 **내용 누락**을 크게 감소.
